# Basic Streamlit App – NBA Player Statistics (1996–2023)

This project is a simple Streamlit-based data visualization tool built for my 2026 Intro to Data Science course. It explores key statistics from a Kaggle dataset of individual NBA player performance across the 1996–2023 seasons. The goal of this  was to practice building an interactive dashboard, perform basic exploratory data analysis (EDA), and visualize trends in NBA player statistics using Python.

**How to Use**
1. Clone the Repository: git clone https://github.com/21ryano/Oesterle-Data-Science-Portfolio.git
2. pip install **Pandas, Matplotlib, Seaborn, and Streamlit**.
3. **Streamlit run** [**PortfolioUpdate1.py**](https://github.com/21ryano/Oesterle-Data-Science-Portfolio/blob/main/EDA/Basic_Streamlit_App/PortfolioUpdate1.py). 

**Features**
- Filter statistics by team and/or season.
- Explore *Player Demographics*, *Top 10 Leaderboards*, *Statistics by Season*, and conduct *Performance Comparisons*.
- Visualizations for every statistic provided.

**Key Takeaways**
- EDA helps uncover trends and relationships in data so that one can understand it better.
- Visualizations are essential as they make it easier to understand distributions, spot outliers, and compare variables.
- Filtering variables allows for more focused analysis and specificity.
