- ### Unsupervised Machine Learning Streamlit App  
[Project Link Here]

An interactive application that allows users to explore datasets using unsupervised learning techniques such as clustering and dimensionality reduction.

**Key Features:**
- Apply clustering algorithms (e.g., K-Means)  
- Use dimensionality reduction techniques (e.g., PCA)  
- Visualize clusters and patterns in data  
- Adjust parameters and instantly see changes in results  

**Summary:**  
This project expands my machine learning experience beyond supervised models by focusing on pattern discovery without labeled data. It strengthened my understanding of how algorithms identify structure in data and how parameter choices affect clustering outcomes.

**Portfolio Contribution:**  
This app complements my earlier supervised learning project by demonstrating a broader machine learning toolkit. It also highlights my ability to build interactive Python applications and deploy data science workflows in a user-facing format.

### Machine Learning Streamlit App  
https://github.com/21ryano/Oesterle-Data-Science-Portfolio/tree/main/MLStreamlitApp

An interactive application that allows users to upload datasets, train machine learning models, and evaluate performance in real time.

**Key Features:**
- Classification: Logistic Regression, Decision Trees, KNN  
- Regression: Linear Regression  
- Adjustable hyperparameters with immediate feedback  
- Performance metrics and visualizations  

**Summary:**  
This project demonstrates how different machine learning models and parameter choices affect outcomes such as accuracy and recall, connecting data preprocessing with full model workflows.
